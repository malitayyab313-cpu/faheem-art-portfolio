# Faheem Art — Website & Admin Panel

A complete website and admin panel that I independently developed as part of my work at DevKey Tech.

I handled the development from start to finish, including the frontend, backend, admin panel, and integration.

## Live Website

[Visit Faheem Art](https://faheemart.com)

## Project Overview

Faheem Art's website presents the business and its work online. The project includes a public-facing website and a dedicated admin panel.

This repository showcases the project and the development work I completed under DevKey Tech.

## My Role

**Full-Stack Developer — Sole Developer**

I was responsible for implementing the entire website and admin panel while working at DevKey Tech.

## My Responsibilities

### Frontend Development
Developed the public-facing website, including page layouts, interface components, and content presentation.

### Backend Development
Implemented the backend functionality supporting the website and admin panel.

### Admin Panel Development
Built the administrative interface and its supporting functionality.

### Application Integration
Connected the frontend, backend, and admin panel into a complete working application.
